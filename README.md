# MCP Transports Working Group

Welcome to the **MCP Transports Working Group** — a collaborative community
focused on improving the usability of transports in the [Model Context Protocol
(MCP)](https://modelcontextprotocol.io), including scalability, reliability, and
semantics.

## Mission

See our [current roadmap](./roadmaps/2027-March.md) for priorities and planned work.

The Transports Working Group coordinates community stakeholders to:

- **Improve transport usability** across MCP implementations
- **Define scalability patterns** for connection pooling, load distribution, and
  resource management
- **Establish reliability standards** for error handling, reconnection, and
  message delivery guarantees
- **Clarify transport semantics** for protocol behavior, message ordering, and
  state management
- **Drive interoperability** across platforms and implementations

> **See the [charter](https://modelcontextprotocol.io/community/working-groups/transports) for detailed scope and processes.**


## Getting Involved

We welcome contributions from anyone interested in MCP transports! Here is how
you can get involved:

1. **Join the community** — Connect on the `#transports-wg` channel in [MCP
   Discord](https://discord.com/invite/6CSzBmMkjX).
2. **Attend meetings** — Join our weekly calls (find the next meeting at
   [meet.modelcontextprotocol.io/tag/transports-wg](https://meet.modelcontextprotocol.io/tag/transports-wg)).
   No approval needed!
3. **Contribute** — Open issues to propose ideas or submit PRs for improvements.

Start with an issue describing the problem and concrete use cases. Keep related
material together under `proposals/<project>/`, using descriptive filenames and
`XXXX-` prefixes for draft SEPs. Include authors, status, and discussion links.
When work moves upstream, link to the official SEP and mark the local draft as
historical. Follow the [MCP SEP guidelines](https://modelcontextprotocol.io/community/sep-guidelines)
for the formal proposal process.

All participants must abide by the **[MCP Code of
Conduct](https://github.com/modelcontextprotocol/.github/blob/main/CODE_OF_CONDUCT.md)**
and adhere to the **[MCP Antitrust
Policy](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/ANTITRUST.md)**.

_See [GOVERNANCE.md](./GOVERNANCE.md) for current members and governance roles._
